# Service: @postolio/schedule-management

This service is the core of the content scheduling system. It is responsible for creating, updating, and managing the lifecycle of scheduled posts and campaigns.

## Development

### Scripts

- **Build:** `pnpm build`
- **Lint:** `pnpm lint`
- **Test:** `pnpm test`

To run any script for only this service from the monorepo root, use the `--filter` flag:

```bash
pnpm --filter=@postolio/schedule-management <script_name>
```
